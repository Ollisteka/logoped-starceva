
# Портфолио логопеда Старцевой Светланы Александровны

Веб-сайт-портфолио для учителя-логопеда Старцевой Светланы Александровны.

## О проекте

Современный адаптивный сайт-портфолио, созданный с использованием React, TypeScript и Vite. Сайт содержит информацию о профессиональной деятельности логопеда и включает следующие разделы:

- **Профиль** - основная информация о специалисте
- **Публикации** - научные и методические публикации
- **Педкопилка** - методические материалы и разработки
- **Наставничество** - работа с молодыми специалистами
- **Спортивные мероприятия** - участие в спортивных событиях
- **Конкурсы** - участие в профессиональных конкурсах
- **Курсы** - повышение квалификации
- **Портфолио** - достижения и награды

## Технологии

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Radix UI компоненты

## Установка и запуск

### Предварительные требования

Убедитесь, что у вас установлены:
- Node.js (версия 18 или выше)
- npm или yarn

### Установка зависимостей

```bash
npm install
# или
yarn install
```

### Запуск в режиме разработки

```bash
npm run dev
# или
yarn dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена

```bash
npm run build
# или
yarn build
```

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите код в репозиторий
3. В настройках репозитория включите GitHub Pages
4. Выберите источник "GitHub Actions"
5. Создайте файл `.github/workflows/deploy.yml` для автоматического деплоя
