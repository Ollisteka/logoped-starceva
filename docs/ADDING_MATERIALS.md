# Руководство по добавлению материалов в секции

Этот документ описывает процесс добавления новых материалов (файлов) в различные секции проекта.

## Общие принципы

1. **Имена файлов** должны быть на английском языке (латиница, дефисы вместо пробелов)
2. **Заголовки материалов** берутся из русских названий файлов
3. **Год** по умолчанию: `2025` (если не указано иное)
4. **Описания** создаются самостоятельно на основе содержания материала 
5. **Категория** выбирается из уже существующих, но, если существующие не подходят, можно создать новую и обновить документацию в файле `ADDING_MATERIALS.md`
6. **Порядок материалов**: новые материалы добавляются в начало массива (отображаются первыми на странице)

## Структура секций

### 1. Педагогическая копилка (`PedkopilkaSection.tsx`)

**Расположение файла**: `src/pages/PedkopilkaSection.tsx`

**Структура материала**:
```typescript
{
  title: 'Название материала', // Русский заголовок
  category: 'Методические материалы' | 'Презентации', // Категория
  year: '2025',
  description: `Описание материала с${NBSP}использованием неразрывных пробелов`,
  downloads: [
    {
      href: getDocumentPath('filename.docx'), // Путь относительно public/documents/
      text: 'Текст ссылки',
    },
    // Для внешних ссылок:
    {
      href: 'https://example.com',
      text: 'Текст ссылки',
      icon: 'link' as const,
    },
  ],
}
```

**Пример добавления материала**:
```typescript
const materials = [
  {
    title: 'Картотека пальчиковых игр',
    category: 'Методические материалы',
    year: '2025',
    description: `Сборник пальчиковых игр для развития мелкой моторики рук и${NBSP}речевой активности у${NBSP}обучающихся`,
    downloads: [
      {
        href: getDocumentPath('finger-games-catalog.docx'),
        text: 'Пальчиковые игры',
      },
    ],
  },
  // ... остальные материалы
];
```

**Порядок**: Новые материалы добавляются в **начало** массива `materials`

**Категории**:
- `'Методические материалы'` - для методических разработок, картотек, сборников
- `'Презентации'` - для презентаций

## Вспомогательные функции и компоненты

### `getDocumentPath(path: string)`

Создает полный путь к документу из папки `public/documents/`.

**Использование**:
```typescript
getDocumentPath('filename.docx') // → '/documents/filename.docx'
getDocumentPath('folder/file.pdf') // → '/documents/folder/file.pdf'
```

**Важно**: Путь указывается относительно `public/documents/`, без ведущего слэша.

### `getPhotoPath(path: string)`

Создает полный путь к фото из папки `public/photos/`.

**Использование**:
```typescript
getPhotoPath('image.jpg') // → '/photos/image.jpg'
getPhotoPath('folder/image.jpg') // → '/photos/folder/image.jpg'
```

### `NBSP` (неразрывный пробел)

Используется для предотвращения разрыва строк в тексте.

**Использование**:
```typescript
import { NBSP } from '../consts/typography';

`Текст с${NBSP}неразрывным пробелом`
```

### `LinkList` компонент

Используется для отображения списка ссылок на скачивание.

**Структура ссылки**:
```typescript
{
  href: string, // URL или путь к файлу
  text: string, // Текст ссылки
  icon?: 'download' | 'link', // Иконка (по умолчанию 'download')
}
```

### `PhotoGallery` компонент

Используется для отображения галереи фотографий.

**Структура**:
```typescript
{
  basePath: string, // Путь к папке в public/photos/
  images: [
    {
      src: string, // Имя файла
      alt: string, // Описание изображения для доступности
    },
  ],
}
```

## Пошаговый процесс добавления материала

### Шаг 1: Подготовка файла

1. Переименуйте файл на английский язык (латиница, дефисы вместо пробелов)
   - Пример: `картотека пальчиковых игр.docx` → `finger-games-catalog.docx`
2. Поместите файл в соответствующую папку:
   - Документы: `public/documents/`
   - Фото: `public/photos/`

### Шаг 2: Определение секции

Определите, в какую секцию нужно добавить материал:
- Методические материалы → `PedkopilkaSection`
- Научные статьи → `PublicationsSection`
- Курсы → `CoursesSection`
- Конкурсы → `CompetitionsSection`
- Наставничество → `MentorshipSection`
- Спортивные мероприятия → `SportsSection`

### Шаг 3: Добавление в массив

1. Откройте соответствующий файл секции (например, `src/pages/PedkopilkaSection.tsx`)
2. Найдите массив материалов (например, `materials`, `publications`, `courses`)
3. Добавьте новый объект в **начало** массива
4. Заполните все обязательные поля согласно структуре секции

### Шаг 4: Проверка

1. Убедитесь, что все импорты на месте
2. Проверьте синтаксис TypeScript
3. Запустите линтер: нет ли ошибок
4. Проверьте отображение в браузере

## Важные замечания

1. **Порядок материалов**: Новые материалы всегда добавляются в начало массива (индекс 0), чтобы они отображались первыми на странице

2. **Неразрывные пробелы**: Используйте `${NBSP}` для предотвращения разрыва строк в важных местах (например, "с${NBSP}обучающимися")

3. **Внешние ссылки**: Для внешних ссылок обязательно указывайте `icon: 'link' as const`

4. **Пути к файлам**: Всегда используйте `getDocumentPath()` или `getPhotoPath()` вместо прямых путей

5. **Типизация**: Используйте `as const` для литеральных типов (например, `'link' as const`)

6. **Описания**: Создавайте содержательные описания, которые помогают понять суть материала
